# DataShield

Privacy Request Assistant — система для генерации и управления запросами на удаление персональных данных в соответствии с требованиями законодательства (FZ-152 / GDPR).

## Описание

DataShield помогает пользователю:

- создать официальный запрос на удаление персональных данных
- автоматически сгенерировать юридически корректное письмо
- сохранить историю обращений
- отслеживать статус запросов

## Стек

- Kotlin
- Jetpack Compose
- MVVM
- Clean Architecture

## Архитектура

data / domain / presentation / ui / di / navigation

## Цель проекта

Создать удобный инструмент для управления запросами на удаление персональных данных и защиты цифровой приватности пользователя.
