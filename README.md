# Datashield
Android application for generating official personal data deletion requests (FZ-152 compliance tool).
Приложение для Android для формирования официальных запросов на удаление персональных данных (инструмент для соблюдения требований ФЗ-152).

Статус проекта 
- Ранний этап разработки (только структура Githun,без Android-кода)

Архитектура проекта 
Проект будет построен по принципам Clean Architecture:
-**data** - работа с данными (база,файлы,API)
-**domain** - бизнесс-логика приложения
-**зpresentation** - логика экранов и состояниие UI
-**ui** - компоненты интерфейса (Compose UI)
-**navigation** - навигация между экранами
-**di** - внедрение зависимостей

Цель проекта
Создать полноценное Android-приложение для Google Play,которое помогает пользователям защищать свои персональные данные.
